# 시뮬레이션 규칙

이 문서는 엔진([src/sim/engine.ts](../src/sim/engine.ts))이 실제로 따르는 규칙을 정리합니다. 규칙을 바꾸면 이 문서도 함께 고쳐야 합니다.

## 2. 개체

- **형태**: 몸은 회전된 직사각형입니다. `width`는 진행 방향 길이, `height`는 진행 방향에 수직인 폭입니다.
- **충돌 판정**: 포식자와 피식자는 회전 직사각형끼리의 분리축 정리(SAT)로 판정합니다. 피식자와 먹이는 회전 직사각형과 원으로 판정합니다. 따라서 몸의 모양(길쭉함, 납작함)이 사냥과 먹이 획득 확률에 실제로 영향을 줍니다.
- **유전자형과 표현형**: 모든 유전자는 항등 매핑입니다. 유전자 값이 곧 표현형입니다.

| 유전자 | 단위 | 의미 |
|---|---|---|
| `width` | 월드 단위 | 진행 방향 길이 |
| `height` | 월드 단위 | 측면 폭 |
| `speed` | 단위/초 | 이동 중일 때의 속력 |
| `activity` | 0–1 | 결정 시점마다 "움직이기"를 선택할 확률 |
| `vision` | 월드 단위 | 감지 반경. 행동 옵션이 켜져 있을 때만 의미가 있음 |

## 3. 틱 순서 (고정 dt = 1/30초)

1. **먹이 생성**: `spawnRate × dt`를 누적하고 `maxCount` 이하로 유지합니다. 위치는 균일 무작위이며, '출입 불가' 구역은 제외합니다.
2. **공간 격자 재구성**: 피식자, 포식자, 먹이를 각각 40단위 격자에 넣습니다.
3. **먹이 섭취**: 살아 있는 피식자는 틱마다 최대 1개를 먹습니다. 에너지는 `gainPerEat`만큼 늘고 `maxEnergy`를 넘지 않습니다.
4. **사냥**: 살아 있는 포식자는 틱마다 최대 1마리를 잡습니다. 포식자를 막는 구역 안의 피식자는 면역입니다. 잡힌 피식자는 즉시 `alive=0`이 되어 같은 틱에서 다른 상호작용에 참여하지 않습니다. 매 틱 포식자 처리 시작점을 무작위로 회전시켜 배열 순서 편향을 없앱니다.
5. **개체 갱신**: 나이 증가 → 수명 사망 → 이동/휴식 결정 → 감지 → 이동 → 벽과 구역 충돌 → 대사 → 굶주림 사망.
6. **번식**: 시작 인덱스를 무작위로 회전합니다. 살아 있는 개체가 조건을 만족하고, 종 개체 수가 상한 미만이고, 대사가 켜져 있다면 `에너지 > offspringEnergy`일 때 자식 하나를 만듭니다.
7. **압축**: 죽은 개체와 먹은 먹이를 순서를 유지한 채 배열에서 제거합니다.
8. **통계 표본**: `sampleInterval`(기본 1초)마다 기록합니다.

## 4. 세부 규칙

### 이동
- 각 개체는 `decisionInterval × U(0.5, 1.5)`초마다 결정합니다. `activity` 확률로 움직이기를 선택하고, 움직일 때는 새 방향을 균일 무작위로 고릅니다. 그렇지 않으면 쉽니다.
- **감지 행동** (기본 꺼짐, V 프리셋에서 켜짐): *이미 움직이는* 개체만 방향을 바꿉니다. 활동성은 *움직일지*를, 시야는 *어디로* 갈지를 정하므로 두 유전자의 효과가 독립적입니다.
  - 피식자: 시야 안의 가장 가까운 포식자 반대 방향으로 갑니다(도망이 먹이 찾기보다 우선). 포식자가 없으면 가장 가까운 먹이 쪽으로 갑니다.
  - 포식자: 시야 안의 가장 가까운 피식자를 쫓습니다(안전구역 안의 피식자는 무시).
- **벽**: 위치를 경계 안으로 고정하고 방향을 반사시킵니다.
- **구역**: 진입이 금지된 종은 경계(반지름 + 몸 반지름) 밖으로 방사 방향으로 밀려나고, 구역 바깥쪽 반원 안의 무작위 방향으로 돌아섭니다. 규칙을 실시간으로 바꾸면 이미 안에 있던 개체도 다음 틱에 밀려납니다.

### 에너지 (대사가 켜진 종만)
```
비용/초 = basal
        + sizeCost     × m
        + speedCost    × m × (speed/40)²   ← 이동 중일 때만
        + activityCost × activity
        + visionCost   × (vision/50)
m = width × height / 36   (기준: 6×6 몸)
```
각 항은 독립 파라미터입니다. 이동 비용은 질량에 비례하고 속도의 제곱에 비례합니다(운동에너지 근사, **추측**).

### 번식 모드
| 모드 | 조건 | 부모 쪽 변화 |
|---|---|---|
| `timer` | 마지막 번식 후 `interval`초 경과 | 타이머 초기화 |
| `eat` | 마지막 번식 후 먹은 수 ≥ `eatThreshold` (포식자는 사냥 수) | 먹은 수에서 기준값을 뺌 |
| `energy` | 에너지 ≥ `energyThreshold` | 없음 |
| `none` | 번식 안 함 | 없음 |

- 대사가 켜져 있으면 부모가 `offspringEnergy`를 자식에게 넘깁니다(에너지 보존). 이것보다 에너지가 적은 부모는 조건이 충족되어도 기다립니다.
- 자식은 부모 바로 옆에 태어나고, 세대는 부모 + 1, 방향은 무작위입니다.
- 무성생식이며 유전체를 복사한 뒤 돌연변이를 적용합니다.

### 돌연변이
유전자마다 독립적으로 다음을 적용합니다.
```
확률 p = clamp(species.mutation.rate × gene.rateMul, 0, 1)
변이:   v' = clamp(v + N(0, σ²), min, max),  σ = species.mutation.strength × gene.strengthMul × (max − min)
```
- 정규분포는 평균 0이라 **방향성이 없습니다**(테스트로 검증). 범위 경계에서 잘리기 때문에 경계 근처에서만 약한 반사 효과가 생깁니다.
- `evolve=false`인 종이나 `evolvable=false`인 유전자는 절대 변하지 않습니다.

### 사망
- **포식**: 포식자에게 잡힘.
- **굶주림**: 에너지 ≤ 0.
- **수명**: `lifespan × (1 ± lifespanJitter)`. 개체마다 출생 시 정해지며, 0이면 불멸입니다.

## 6. 결과를 해석할 때

- **자연선택과 부동을 구분하려면 시드를 여러 개 돌리세요.** 한 번의 실행에서 보인 변화는 우연일 수 있습니다. 시드 대부분에서 같은 방향이면 선택일 가능성이 높고, 방향이 제각각이면 부동입니다.
- **개체 수가 작으면 부동이 강합니다.** C 프리셋의 피식자 40–100마리 수준에서는 한 시드의 궤적이 크게 흔들립니다.
- **대조군을 쓰세요.** `evolve=false`(돌연변이 없음) 실행은 형질이 절대 변하지 않음을 보여 줍니다.
- **경계 효과에 주의하세요.** 유전자가 `min`/`max`에 붙으면 선택이 더 이상 작동할 수 없습니다(예: A의 속도 0).
- **상한 효과**: 개체 수가 `maxPopulation`에 도달하면 출생은 사망으로 생긴 자리만큼만 일어납니다. 이때 적합도는 "얼마나 오래 살아남아 빈자리를 차지할 기회를 얻는가"가 됩니다.
